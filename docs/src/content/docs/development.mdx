The library and `csp` binary are a Cargo workspace. `crates/csp` holds both the library and the `csp` binary, which sits behind the default-on `cli` feature; `crates/csp-node` holds the napi-rs bindings published as `@pleaseai/csp-sdk`.

```bash
cargo build --release          # build the csp binary → target/release/csp
cargo test --workspace         # run tests
cargo fmt --all                # format
cargo clippy --all-targets --all-features -- -D warnings   # lint
```

Run the CLI from source:

```bash
cargo run -p code-search-please -- search "query" .
```

## Repository layout

| Path | Contents |
|------|----------|
| `crates/csp` | The Rust library and the `csp` binary (CLI + MCP server). |
| `crates/csp-node` | napi-rs bindings, shipped as `@pleaseai/csp-sdk`. |
| `npm/` | The `@pleaseai/csp` npm launcher that execs the platform binary. |
| `plugins/csp` | The Claude Code / Codex plugin. |
| `docs/` | This documentation site (Cloudflare Nimbus). |

## Documentation site

The docs live in `docs/` and are built with [Nimbus](https://nimbus-docs.com):

```bash
cd docs
bun install
bun run dev      # local preview
bun run build    # static build → docs/dist
bun run check    # build-free preflight (config, frontmatter, links, types)
```
