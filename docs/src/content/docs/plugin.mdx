The fastest way to set up `csp` is the plugin, which registers the `csp-search` helper and, optionally, the MCP server. It ships for both Claude Code and Codex.

<Tabs>
  <TabItem label="Claude Code">
    Claude Code installs the two halves as separate plugins, so you can skip the MCP server:

    ```text
    /plugin marketplace add pleaseai/claude-code-plugins
    /plugin install csp@pleaseai       # csp-search sub-agent + skill (CLI)
    /plugin install csp-mcp@pleaseai   # optional: the csp MCP server
    ```

    If you installed `csp-mcp`, restart Claude Code or run `/mcp` to confirm the `csp` server is connected.
  </TabItem>
  <TabItem label="Codex">
    ```bash
    codex plugin marketplace add pleaseai/claude-code-plugins
    codex plugin add csp@pleaseai
    ```
  </TabItem>
</Tabs>

## What the plugins install

- **`csp-search` helper** (`csp`): a dedicated sub-agent (`agents/csp-search.md`, Claude Code) and skill (`skills/csp-search/SKILL.md`, Claude Code and Codex) that run `csp search` and `csp find-related` through the CLI with the right flags.
- **MCP server `csp`** (`csp-mcp` on Claude Code, bundled in `csp` on Codex): exposes the `search` and `find_related` tools, launched via `bunx @pleaseai/csp mcp`. Repos are cloned and indexed on demand; local paths are watched and re-indexed automatically.

## Requirements

[Bun](https://bun.sh) 1.3.10+ must be on your `PATH` so `bunx` can launch the MCP server. Node.js 22+ also works via `npx @pleaseai/csp mcp` (edit the MCP config if you prefer npm). The `csp-search` helper calls the `csp` CLI, so a Homebrew install (`brew install pleaseai/tap/csp`) is enough if you skip the MCP server; otherwise it falls back to `bunx @pleaseai/csp`.

## Customization

By default the MCP server indexes only code files. To also index documentation or config, append `--content` to the server args, for example `["@pleaseai/csp", "mcp", "--content", "all"]`. A single tool call can also override this with its `content` argument (`code`, `docs`, `config`, or `all`).

## Layout

`plugins/csp` carries both the Claude Code and Codex manifests; each harness reads its own and ignores the other. `plugins/csp-mcp` is Claude Code only.

| | Claude Code | Codex |
|---|---|---|
| Manifest | `plugins/csp/.claude-plugin/plugin.json` | `plugins/csp/.codex-plugin/plugin.json` |
| MCP config | `plugins/csp-mcp/.mcp.json` (`mcpServers`) | `plugins/csp/.mcp.codex.json` (`mcp_servers`) |
| Helper | `agents/csp-search.md` (sub-agent) and `skills/csp-search/SKILL.md` (skill) | `skills/csp-search/SKILL.md` (skill) |

The plugin sources live at [plugins/csp](https://github.com/pleaseai/code-search/tree/main/plugins/csp) and [plugins/csp-mcp](https://github.com/pleaseai/code-search/tree/main/plugins/csp-mcp) in the repository.
